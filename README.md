# What is this?

> **The zero-cost, ultra-fast Gemini coding agent powered by Lovable architecture.**

waguri brings the intelligence and precision of Google’s Gemini models directly into a high-powered, autonomous software engineering environment—**without burning through expensive API credits.**

By leveraging Lovable’s open, high-speed backend execution layer and pre-configured API routing, GemDev provides full-stack AI development capabilities completely free during its Beta phase.

---

## features

* **Zero API Costs:** Built on top of Lovable’s backend integration layer, allowing you to build, debug, and scale without setting up personal billing.
* **Full-Stack Autonomous Coding:** Generates complete features, fixes bugs, refactors spaghetti code, and manages boilerplate automatically.
* **Instant Live Previews:** Integrated runtime environment to see UI updates in real time as GemDev writes code.
* **Gemini-Engineered Intelligence:** Superior reasoning across large codebases, long-context understanding, and multi-file project restructuring.
* **Context-Aware Refactoring:** Understands dependencies across your entire project workspace, not just the single file open in your editor.
